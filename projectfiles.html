Abstract — This document provides specifications and distribution archives for the Transistor motion graphics composition. The project incorporates algorithmic timing and keyframe transitions executed via vanilla Adobe After Effects expression pipelines, with color correction utilizing the Magic Bullet Looks suite. External media assets and raw composition packages are cataloged below.

Key words — After Effects • Transistor • Motion Graphics • JSX Scripting • Project Archives

1. Technical Specification & Manifest

The Transistor project file contains the master composition, expressions, and keyframe timelines utilized in our motion graphics and hardware visualization reels. When opening or compiling the project, please observe the following technical parameters:

Transistor/note.txt:
1. I own none of the third-party assets in the edit and therefore am not including them with the project file.
2. The only plugins used were from the Magic Bullet Looks Suite; everything else is vanilla Adobe After Effects or JSX scripts.

2. Archive Distribution & Packages

The verified archive is packaged as Transistor.zip (4.8 MB uncompressed) containing Transistor.aep and configuration notes. Readers may download the package directly from this server or access the external Dropbox mirror:
