Projects & Experimental Systems: Microarchitectures, Discrete Feedback Controls, and Memory Topologies

Thomas Koetting
Department of Electrical Engineering & Computer Science, University of Kansas
Silicon Research Collective, Overland Park

Abstract — This manuscript details five applied engineering repositories developed to investigate discrete computation across multiple abstraction layers. Implementations include an RV32I-compliant 32-bit pipelined RISC-V microcontroller synthesized in Verilog, a low-latency server utilities daemon for distributed Minecraft environments, a discretized proportional-integral-derivative (PID) feedback compensator with live canvas simulation, a lock-free circular ring buffer utilizing power-of-two modulo pointer arithmetic, and an iterative-addition operational amplifier. An embedded demonstration reel showcases dynamic hardware behavior.

Key words — RISC-V • Microcontroller • PID Control • Circular Ring Buffer • Verilog • Operational Amplifier

2. 32-Bit RISC-V Microcontroller

In @tkoetting03/32-bit-risc-mcu, we implement a synthesized 32-bit processor core compliant with the unprivileged RV32I base integer specification. The core executes arithmetic, logical, memory-access, and branch instructions across a classical five-stage instruction pipeline consisting of:

  • Instruction Fetch (IF): Program counter indexing with dual-port instruction memory.
  • Instruction Decode (ID): Immediate sign extension and dual-read 32-register file access.
  • Execution (EX): 32-bit ALU executing branch evaluations and arithmetic operations.
  • Memory Access (MEM): Data memory interface with byte, halfword, and word masking.
  • Write-Back (WB): Multiplexed register retirement.

Forwarding logic and hazard detection units resolve data dependencies with minimal branch misprediction stalls. The repository contains full Verilog HDL source and simulation testbenches.

3. Server Utilities Minecraft Mod

Distributed multi-tenant sandbox environments demand efficient memory allocation and deterministic event scheduling. In @tkoetting03/server-utilities, we authored a high-throughput server modification engineered to optimize tick rates, reduce packet serialization overhead, and manage world states with minimal GC latency.

4. Real-Time PID Controller in C

Stable physical automation necessitates closed-loop regulation. In @tkoetting03/PID-Tuner, we formulate a discrete-time proportional-integral-derivative feedback algorithm:

$$u(t) = K_p \, e(t) + K_i \int_0^t e(\tau) \, d\tau + K_d \, \frac{de(t)}{dt}$$

5. Lock-Free Circular Ring Buffer in C

High-performance systems programming precludes dynamic heap allocation in time-critical paths. In @tkoetting03/Ring-Buffer, we develop a fixed-capacity circular FIFO buffer utilizing power-of-two bitwise pointer wrapping:

$$\text{head}_{\text{next}} = (\text{head} + 1) \pmod N, \quad \text{count} = (\text{head} - \text{tail}) \pmod N$$
(2)
